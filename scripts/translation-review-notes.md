## recIBODr35D8FrvUY — shortest book in the Bible
- Telugu: "బైబిల్ లో అతి చిన్న గ్రంథము ఏది?" (options: యూదా / ఓబద్యా / ఫిలేమోనుకు / 3 యోహాను, correct = 3 యోహాను)
- Translation: "What is the shortest book in the Bible?" / "3 John"
- Note: Trivia convention varies — Obadiah is shortest by chapter count (1 chapter),
  3 John is shortest by word count. The Telugu reference explicitly says word count,
  so the EN/KN reference lines were translated to match ("shortest by word count"),
  but flagging in case the app intends the more common "shortest book" framing to
  mean Obadiah instead.

## recjRIlwKuhyfgdrW — Paul's vision on the way to Macedonia
- Telugu: "పౌలుకు కర్తగె పట్టణమునకు రమ్మని పిలుచు మనుష్యుని దర్శనము కలిగెనా?"
- Translation: "Did Paul have a vision of a man calling him to the city of Carthage?"
- Note: The Telugu transliteration "కర్తగె" was rendered as "Carthage" (and Kannada
  "ಕರ್ತಾಗ್"). This is a distractor option (the correct answer is Macedonia per Acts 16:9),
  so accuracy of this specific place name doesn't affect gameplay, but worth a native
  speaker double-checking the intended city name behind the transliteration if it
  matters for phonetic consistency.
